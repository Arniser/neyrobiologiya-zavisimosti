<h2>2. Какие 5 ключевых зон мозга участвуют в формировании риска?</h2>

<p>Процесс принятия рискованных решений задействует сложную сеть нейронных связей. Каждая зона выполняет специфическую функцию.</p>

<ul>

	<li><strong>Миндалевидное тело (Amygdala):</strong> Обрабатывает эмоции, особенно страх и стресс. Гиперактивность этой зоны вызывает тревогу при невозможности играть.</li>

</ul>
